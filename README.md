# BETAFPV F405 (APM32) Configuration

Этот репозиторий содержит **единственный актуальный файл настроек** для полетного контроллера BETAFPV F405 (также известного как TBF79 или FF405 V04).

## Рекомендуемая прошивка
Файл настроек сделан строго под прошивку:
**`Betaflight / APM32F405 (A405) 2026.6.2 Sep 16 2026 / 21:44:43 (e0b7bb01b) MSP API: 1.48`**

## Как применить настройки:
1. Откройте конфигуратор Betaflight.
2. Перейдите во вкладку **CLI** (Командная строка).
3. Откройте файл `BETAFPVF405_APM32_Config.txt` из этого репозитория.
4. Скопируйте всё его содержимое.
5. Вставьте в строку ввода CLI и нажмите **Enter**.
6. Плата автоматически сохранит настройки и перезагрузится.

## Что включает в себя этот конфиг:
- **Распиновка:** Точные порты для моторов (A03, B00, B01, A02), датчиков тока и напряжения (C01, C02).
- **Радио:** Протокол CRSF (Crossfire / ELRS) настроен на порт UART3.
- **Моторы:** Протокол DSHOT600, 14 полюсов, 900Kv. Направление вращения моторов — наружу (`yaw_motors_reversed = ON`). Двухсторонний DShot (bidir) отключен для стабильности.
- **Таймеры и DMA:** Жестко прописаны для предотвращения конфликтов в новых версиях Betaflight.
